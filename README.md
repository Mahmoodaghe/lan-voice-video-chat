# عميل وخادم صوت وفيديو عبر UDP

مشروع بسيط لمحادثة صوتية ومرئية على شبكة محلية. يستقبل الخادم حزم UDP ويعيد بثها إلى بقية العملاء المتصلين.

## المتطلبات

- Python 3.10 أو أحدث
- كاميرا وميكروفون ومكبرات صوت لكل جهاز عميل
- منافذ UDP ‏20000 للفيديو و20001 للصوت متاحة على جهاز الخادم

## التثبيت

أنشئ بيئة افتراضية وثبّت الحزم:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

على Windows، قد يحتاج تثبيت `PyAudio` إلى wheel متوافق مع إصدار Python ونظام التشغيل إذا لم يتوفر تثبيته مباشرة عبر pip.

## التشغيل

1. شغّل الخادم على جهاز واحد:

   ```powershell
   python server.py
   ```

   يستمع الخادم افتراضيًا على جميع واجهات الشبكة. يمكن تحديد واجهة بعينها عبر متغير البيئة `SERVER_HOST` قبل تشغيله في PowerShell، مثل:

   ```powershell
   $env:SERVER_HOST = "0.0.0.0"
   python server.py
   ```

2. اسمح بحركة UDP الواردة على المنفذين 20000 و20001 في جدار حماية جهاز الخادم، ضمن الشبكة الموثوقة فقط.
3. شغّل العميل على كل جهاز:

   ```powershell
   python client.py
   ```

4. أدخل معرّفًا من حرف واحد وعنوان IP أو اسم المضيف لجهاز الخادم، ثم اضغط **Start**. يجب أن يكون لكل مشارك معرّف مختلف.

اضغط **Stop** لإغلاق العميل، أو `Ctrl+C` لإيقاف الخادم.

## ملاحظات أمنية

هذا المشروع للتجربة على شبكة محلية موثوقة فقط. الصوت والفيديو يرسلان دون تشفير أو مصادقة، ويستطيع الخادم إعادة بث الحزم الواردة. لا تعرض المنافذ مباشرة على الإنترنت، ولا تستخدم المشروع لنقل بيانات حساسة.
